# hxyfront-62014 赛鸽训放记录

源提示词编号：9

面向赛鸽棚的训放记录前端工具：按批次登记开笼，逐羽记录归巢，自动算分速、排名次、生成未归巢提醒。

## 功能

- **训放批次**：登记线路、公里数、天气、开笼时刻和预计分速（用于推算应归时刻）；批次内逐羽上笼，登记归巢时刻与定位信号。
- **鸽籍档案**：逐羽登记足环号、血统、健康状态、配偶（双向绑定）；单羽页汇总历次开笼成绩与当前配偶。
- **成绩排行**：分速 = 公里数 × 1000 ÷ 飞行分钟；健康「观察中」的赛鸽保留成绩档案但不占名次。
- **待联系清单**：超过应归时刻未归巢的自动入清单，无定位信号的排最前，可一键登记归巢。
- **血统筛选**：顶栏筛选后，总览指标、排行、待联系数量同步联动。
- **本地保存**：所有数据写入 localStorage，重开浏览器仍保留。

## 代码结构（保存 / 计算 / 页面分离）

```
src/
  lib/
    types.ts    数据模型（赛鸽 / 批次 / 参赛记录）
    calc.ts     纯计算：分速、应归时刻、排行、待联系、总览统计
    storage.ts  localStorage 读写
    seed.ts     首次打开的演示数据
    format.ts   时间与数字格式化
  pages/        总览 / 批次 / 排行 / 待联系 / 鸽籍 五个页面
  App.tsx       导航、全局血统筛选、数据操作（Ops）
```
