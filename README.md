# 鸽棚台账 · 赛鸽训放记录

面向赛鸽棚的训放台账前端：记录开笼批次与逐羽归巢，自动计算分速，跟踪超时失联，管理血统、健康与配对。

## 功能

- **鸽棚总览**：在棚羽数、归巢率、历史平均分速、待联系数量（含超时无信号紧急数），随血统筛选联动。
- **开笼批次**：新建批次填写线路、公里数、天气、开笼时刻、预计归巢时长（可按 650 米/分自动估算），逐羽勾选参赛鸽；批次台账中逐羽做归巢登记，分速按里程 ÷ 飞行分钟自动计算，可撤销重记。
- **待联系清单**：在飞鸽按「超时且无定位信号 → 超时但有信号 → 未到点」排序，倒计时每 30 秒刷新；可一键切换定位脚环信号。
- **成绩排行**：按分速降序排名，可按批次查看；健康观察中的鸽子有成绩、单列展示但不进名次。
- **赛鸽档案**：登记足环、血统、健康、配偶（双向绑定）与备注；单羽页汇总历次开笼、归巢与当前配偶，支持编辑和删除。
- **血统筛选**：侧边栏切换后，总览指标、排行与待联系数量同步更新。
- **本地持久化**：所有数据保存在 `localStorage`，重开浏览器仍保留；可一键恢复演示数据。

## 代码结构（保存 / 计算 / 页面分离）

```
src/
  types.ts            数据模型
  lib/calc.ts         纯计算：分速、超时判定、待联系排序、排行、统计
  lib/time.ts         时间格式化
  lib/seed.ts         首次打开的演示台账
  store/store.tsx     保存层：reducer + localStorage 持久化
  hooks/useNow.ts     实时时钟（驱动倒计时）
  components/ui.tsx   徽章、面板等通用组件
  pages/              总览 / 批次 / 排行 / 待联系 / 档案 五个页面
  App.tsx             侧边栏、血统筛选与页面切换
```
